# Логирование

Проект использует стандартный модуль `logging`.

## Реализация

- `CDDA_editor/app_logging.py` настраивает логгер `CDDA_editor`.
- `CDDA_editor/app_paths.py` определяет папку программы для исходников и PyInstaller-сборки.
- `configure_app_logging()` добавляет вывод в консоль и файл.
- Файл по умолчанию: `logs\editor.log` рядом с программой.
- Для тестов путь к логу можно передать явно.
- Файловый handler открывает файл на каждую запись и сразу закрывает его, чтобы Windows не блокировал временные каталоги и ротацию.

## Что Логируется

- старт приложения;
- открытие папки мода или JSON-файла;
- создание стартового бэкапа;
- восстановление бэкапа;
- создание автобэкапа;
- сохранение всех, dirty и текущего файла;
- ошибки этих операций через `logger.exception`.

Предупреждения загрузки JSON по-прежнему хранятся в `ModProject.load_warnings` и показываются в GUI. Для совместимости с текущим workflow они также печатаются в консоль с префиксом `[WARN]`.
