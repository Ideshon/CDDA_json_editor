# Архитектура

Проект - Windows-приложение на Python/PyQt5 для редактирования JSON-модов Cataclysm: Dark Days Ahead.

## Слои

- `CDDA_editor/project.py` - модель проекта: загрузка JSON, список объектов, dirty-файлы, сохранение, индексы объектов и связей.
- `CDDA_editor/action_history.py` - история действий редактора: хранит снимки состояния проекта для undo/redo и восстанавливает модель через `ModProject`.
- `CDDA_editor/json_io.py` - чтение и запись CDDA-подобного JSON: комментарии, trailing commas, поток объектов верхнего уровня.
- `CDDA_editor/app_paths.py` - локальные пути файлов программы: `logs\editor.log` и `settings.ini` рядом с исходниками или exe.
- `CDDA_editor/app_logging.py` - настройка логирования в консоль и файл.
- `CDDA_editor/main.py` - главное окно, меню, дерево объектов, команды открытия, сохранения и undo/redo.
- `CDDA_editor/editor.py` - редактор выбранного объекта и его полей.
- `CDDA_editor/relationships.py` - неблокирующее окно связей выбранного объекта с входящими/исходящими ссылками, переходом к объектам и сохранением пользовательского состояния окна через `QSettings`.
- `CDDA_editor/schemas/` - описания поддерживаемых типов объектов и полей.
- `tests/` - проверки через стандартный `unittest`.

## Правила

- `Slaanesh/` - эталонный локальный мод. Его нельзя удалять и нельзя изменять напрямую без отдельной просьбы.
- Сохранение должно проверяться на временных копиях эталонного мода.
- UI вызывает методы модели, но не должен хранить бизнес-логику сохранения и индексации.
- Поведенческие изменения делаются через TDD: сначала падающий тест, затем реализация.
