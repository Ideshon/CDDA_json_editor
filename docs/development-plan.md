# План Развития

## Завершено

1. Стабилизирована структура рабочей папки.
2. Добавлены Poetry, Windows helper-команды и PyInstaller-сборка.
3. Добавлены тесты загрузки и сохранения на копиях `Slaanesh/`.
4. Разделены базовые UI-виджеты.
5. Исправлен Windows workflow через `tasks.cmd`.
6. Добавлены видимые предупреждения загрузки JSON.

## Завершено В Текущем Цикле

Фаза 1: объектный контекст и индексы.

- Файл выбранного объекта показывается в редакторе.
- `ModProject` ведет индекс объектов по `type/id`.
- `ModProject` ведет первый индекс связей по полям `ref_list`.

## Завершено В Текущем Цикле

Фаза 2: перемещение объектов между файлами.

- `ModProject` умеет перемещать один или несколько объектов между JSON-файлами.
- Старый и новый файл помечаются dirty.
- Новый целевой файл создается при сохранении, если его еще нет.
- Дерево объектов поддерживает множественное выделение.
- В UI добавлена команда перемещения выбранных объектов в JSON-файл.

## Завершено В Текущем Цикле

Фаза 3: переименование объектов.

- `ModProject` умеет переименовывать объект и обновлять индекс `type/id`.
- Переименование отклоняет пустой id и дубликаты.
- При включенном обновлении зависимостей переписываются найденные входящие `ref_list` ссылки.
- UI предупреждает о входящих ссылках и предлагает обновить их или переименовать только объект.

## Текущая Фаза

Фаза 4: безопасность данных, бэкап, автобэкап и отмена действий.

- Первым приоритетом добавлено автоматическое создание бэкапа мода при открытии папки мода или отдельного JSON-файла.
- Первым приоритетом добавлена кнопка/команда восстановления из созданного бэкапа.
- Вторым приоритетом добавлен автобэкап во время работы, чтобы уменьшить риск потери прогресса при ошибках и краше программы.
- Для автобэкапа добавлены настройка включения/отключения и настраиваемый интервал.
- Перед undo/redo добавлено запоминание состояния окна, положения тулбаров и размеров панелей.
- Перед undo/redo добавлено логирование в консоль и файл.
- Следующий шаг: добавить кнопки назад/вперед для отмены и повтора действий.
- Эта фаза стоит перед окном связей, потому что сначала нужно защитить данные пользователя от потери при дальнейших операциях редактирования.
